# PTB NoSpherA2 release files — 1 October 2026

This release embeds the size-preserving Yb g4 fit (job 603385). The 717-case
training score improved from 0.019426166410 (previous released defaults) to
0.019127715299; the held-out 169-case validation score improved from
0.018851480493 to 0.018606902088. Selection used training only.

The Yb free-ion gate is zero, with 24/22/21 electrons for charges 0/2+/3+.
The d and f AO shell radii are unchanged. Independent NoSpherA2 export at
orders 32 and 64 passed electron counts and convergence for all three ions.

The Windows executable requires `libiomp5md.dll` beside it, as in the previous
NoSpherA2 release. The Linux executable is fully static. Both macOS slices
depend only on macOS Accelerate and libSystem, with no Homebrew runtime needed.

All four platform/architecture builds ran Yb 0/2+/3+ from embedded defaults.
Their electron counts matched 24/22/21 within 1e-6; density matrices differed
from Windows by at most 2.19e-6. The Windows embedded Yb densities are bitwise
identical to the validated parameter-file candidate; Tm and La are bitwise
unchanged from the previous released executable.

The Yb basis change relative to upstream vDZP described in `README.md` remains
in effect. Release assets and `SHA256SUMS` are in `build/release_g4_20261001/`.
The fitted parameter file, gate evidence, and build scripts are in the source
repository.
